Lab 1 Questions
1. Write a program to store details of any two students such as name, roll, branch. Take input from the user and show their details.
2. Design a program to convert a procedural implementation of a student record system into an object-oriented approach using classes and objects.
3. Write a program to create a class for Point having x and y. Create two methods as input and show.
Input method should take the value of x and y from the keyboard.
Show method will print the value of x and y.
Create any two objects in main() and call input() and show() methods respectively.
4. Write a program to create a class for Time having hh, mm and ss. Create an input method that takes values as parameters and sets the values to the corresponding variables. Create another method called show that will print the value in hh:mm:ss format. Create any two objects in main() and call input() and show() methods respectively.
